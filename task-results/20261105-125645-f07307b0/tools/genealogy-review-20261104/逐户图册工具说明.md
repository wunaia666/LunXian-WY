# 逐户系谱图生成与核对

工具接收指定主稿、已有关系底稿、分户规则和本地补录依据，生成逐户可编辑演示文稿及整册文件。人物姓名和正文处于同一文本框；配偶另设人物框。源文档只读。

## 使用顺序

1. 使用 `build_household_atlas.py` 读取主稿及经核对的分户规则，优先整户单页；超过容量时，依原稿先后逐支分页。
2. 使用 `audit_household_atlas.py` 将原稿记录、正文续行和家族说明回查到图册，核验人物框、婚配、上下代接线、页面边界、框间碰撞及连线穿字。
3. 使用已有的 `check_native_presentation.py` 在本机演示程序中检查全部文字边界、导出打印稿，并在副本中检查文字及连线可编辑、保存后可重开。
4. 将实际打印稿传给核对工具的 `--pdf` 参数，逐段回读人物文字。
5. 如需另制省略重复子女数量和名单的版本，使用 `make_household_concise.py`。这一版本保持姓名、人物框位置和亲属接线不变，保留待核及特殊关系信息。
6. 配偶统一下置时，主入口增加 `--partners-below`。程序比较不同人物框宽度，在保留字号和原文的前提下选择页数较少的方案。配偶以“配／继配”注明身份，后代从家庭资料下沿的中心直线接续，不使用侧绕线。
7. 使用 `review_household_order.py --layout 版面文件 --out 输出目录`，检查配偶下置、同代对齐、子女先后、跨页房支顺序以及每条实际直线的端点；另生成可筛选的待审核清单及文本副本。清单同时扫描人物附注和正文中的“待核”，不能只沿用旧清单。
8. 人物介绍版可在省略名单入口增加 `--clean-introductions`。去掉页顶制作说明和普通子女数量摘要，保留人物介绍、婚嫁、合葬、特殊关系及核查说明，生成整册与逐户独立文件。人物标题、位置和接线应与已核图册逐项比较。
9. 核查信息只在独立文件显示时，再增加 `--external-review`。同时运行 `make_external_review_report.py --layout 已核原版面 --list 原审核清单 --out 独立审核目录`。报告区分需要确认的事项与已纠正留档事项，逐项列原文、相关亲属、具体原因、核查问题和空白确认栏。隐藏图中标记不改变关系的确认状态；移出的全部说明必须能回查到独立报告。

## 依赖与参数

三个入口均使用现有族谱工具目录中的排字、中文数字和原生演示文稿写出模块。主入口参数为 `--source`、`--data`、`--rules`、`--plan`、`--out`；路径由调用方提供。

补录依据应保存在本地资料目录中。新增记录必须指向明确原稿段；有姓名的记录须在该段找到姓名。未具名亲属应明确标记，不能补造姓名。同人归并使用单独映射保留两处原始记录，生身、承嗣信息同时保留。

名单断行曾被误提取成独立人物时，必须另存 `continuation_of` 依据，将其原文归回同户相邻的配偶记录；原始提取记录与来源段号继续保留。不能把这种归位当成同人归并，也不能直接删除该段原文。

分页候选除容纳人物外，还必须让每条已记录的上下代关系至少在一页完整连出。人物均有出现而父子分别落在不同页、没有完整接线的候选方案会被排除。

## 核验边界

自动核验能够发现底稿记录未入图、原文片段缺失、同页多框、关系线缺失、文本框重叠、连线穿字及导出文字缺失。它不能代替对原始关系事实的人工确认。姓名异写、原文称谓矛盾、代际缺层或亲属归属不明时，应保留原记并标为待核。

大幅画布用于保留整户关系。打印时须说明实际纸幅，不能把大幅图直接缩成普通纸张后仍宣称字号可读。

## 归档范围

仅归档通用程序和本说明。主稿、人物底稿、补录依据、族谱姓名、核对台账和办公交付物均不属于程序归档内容。
