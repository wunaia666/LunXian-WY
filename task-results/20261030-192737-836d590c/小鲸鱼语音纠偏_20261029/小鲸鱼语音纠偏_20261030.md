# 小鲸鱼语音纠偏记录（2026-10-30）

## 一句话结论

线上"不像"不是玄学，是链路问题：日常语音一直在跑**二代模型的 instruct2 路径**，这条路径几乎丢掉了参考音的音色——基频只有 324–333 Hz，声纹诊断余弦 0.23–0.24，而参考原声是 480 Hz。换三代模型逐句合成后，同一句话基频回到 378–414 Hz，余弦升到 0.55–0.60。

## 实测数据（同一段台词，同一条原声）

| 路径 | 基频 | 声纹余弦（只作诊断） |
|---|---|---|
| 参考原声 | 480 Hz | 1.00 |
| 线上短句（二代 instruct2） | 324 Hz | 0.24 |
| 三代短句（新链路） | 378 Hz | 0.55 |
| 三代短句 + 音高对齐 | 480 Hz | 0.57 |
| 线上长段（二代 instruct2） | 333 Hz | 0.23 |
| 三代长段（新链路） | 414 Hz | 0.60 |
| 三代长段 + 整体音高对齐 | 453 Hz | 0.65 |
| 三代长段 + 分段音高归一 | 471 Hz | 0.65 |

声纹余弦只能做相对排查，不等于听感百分比。
