# 复刻与动效故障排查

本页整理《南宋人生》静态复刻及动画增强、《核心破局》截图复刻与背景改造中遇到的问题。按主技能的入口按需阅读：静态复刻读第一节；在可编辑底稿上添加或维护原生动画时，读第二节，涉及静态外观或对象变更再回查第一节。本页只补充处理办法；[主技能](../SKILL.md)仍决定拆分粒度、素材取得顺序和最终验收。

## 一、截图复刻

| 发现的问题 | 实际处理办法 | 复检与结果边界 |
|---|---|---|
| 用整页的深浅像素推断文字字界，浅色牌匾、边框和其他笔画干扰测量，校准后反而错位 | 撤回受污染的校准。从稳定底稿在临时副本中逐个隔离对象，用目标演示软件渲染字界；带填色的对象必要时在副本隔离填色或用有字、无字对照。先定字体、字号、字距和行距，再校位置 | 校准只提供定位依据，原尺寸叠加和必要局部仍要复核。本例原书法字体无法唯一确认，系统楷体只能近似，不能据字界贴合判定字形一致 |
| 不规则纸签只有文字可改，或者移开文字后只剩透明矩形 | 按原轮廓重建自由曲线，把原生文字体放进同一形状，保留文字样式、填色、描边和图层位置；删除被替代的文本框与旧底，更新对象登记 | 在验证副本对同一对象改字、改填色、实际移动至少一个顶点，再保存重开。对象合并后重新核对文字与填色都能显示，不能只查顶点数量 |
| 隐藏原生标签后，图片层仍露出旧字、描边或标注；扩大擦除区又损伤原场景 | 分开查看原生对象、图片和背景层。按[素材优先级](背景与透明素材.md#图片素材提取与还原优先级)先查原素材和原图可保留区域；本例仅在普通修复不能自然补全的遮挡区用参考图修复，并用掩膜把补全部分合回原素材 | 逐个移开受影响的文字和标签，检查旧位置；再移开复杂主体和全部前景检查底色。可保留画面自身的招牌和书册文字，但要与后加标注区分。第七、九页的遮挡补全是推补，无法证明恢复了被盖住的原始像素 |
| 把纸纹和纸色烘在一起后不能独立换底色；或对图片全幅抠色，误伤亮部和家具内部 | 将无字纸纹做成独立透明层，底色与低频明暗用原生渐变重建。透明范围按外沿遮罩控制，保留主体内部应不透明的亮部、家具和细节；不要把带底色的矩形裁块充当透明主体 | 在明暗两种底色下查看边缘、孔洞和残片，实际移动、缩放及替换图片；移开纹理和其余前景后，应只剩干净的原生背景。仅有透明通道不证明遮罩正确 |
| 最后改了一处纸签，预览、对象登记和差异图仍指向前一版 | 最终保存后固定文件摘要，以同一份文稿重新导出受影响页并核对全部页的证据版本；记录原图、原生导出、对象登记和最终文件的对应关系 | 原尺寸文件用于程序对照；只查看 `_ai小图` 的压缩副本，遵守主技能的看图上限。格式通过、原生打开、无残留和视觉一比一分别记录；不得用压缩图代替原尺寸对照 |

复检时先看移开目标对象后露出的那一层，再看全部前景移开后的底层。全空背景只证明底色干净，不能替代对图片中旧字、旧边框和重复残片的检查。文字识别可辅助定位残字，仍须检查低对比度区域和透明边缘。

### 背景换色、色框与透明插画

| 发现的问题 | 处理办法 | 必须复检 |
|---|---|---|
| 页面底色在设置里能改，画面却几乎不变 | 确认是不透明的整页对象、母版图形还是背景填充。将底色放入幻灯片原生背景属性；需保留的场景装饰单独列层。用户要求去背景时，只移除背景层；用当前底稿另存成稿，保留前景及其素材关系 | 在验证副本换成反差明显的色值并保存重开，检查页边、栏间和前景间隙。仅修改背景时，核对前景位置、样式、层次和素材关系未变 |
| 刷痕和字分别做成对象，移动时留下一半 | 将文字和色框置于同一带填色原生对象；不规则外沿用有文字体的自由曲线。仅在用户允许时简化为规则圆角；清除原图中被替代的字和色块 | 同一框改字、改填色、移动，需保留不规则边时实际改顶点。移开该框检查原位，再隐藏全部前景 |
| 浅色耳麦在浅底看不出问题，换深底却出现锯齿和破洞 | 用外轮廓限定透明范围；对主体内部本应保留的白色或浅色区域增加保护遮罩，保留真正镂空，避免按颜色一刀切 | 在明暗两种底色查看完整轮廓、孔洞、光晕和矩形边缘。半透明像素计数只证明存在透明通道，不能证明轮廓正确 |
| 移动人物后字标留在原位，或隐藏新字标后露出图片里的旧字 | 先在原素材层清除旧字标及抗锯齿边并修补主体，再用原生文字重建；若字标视觉上附着于人物，只对这一局部建立原生组合 | 移动整组检查原位无字标，单独隐藏新字标检查图片无旧字，展开组合验证文字仍可单独改动 |
| 字体未知，高光等短句字距过紧，红框内三行正文贴边 | 核查本机字体，从接近字形的字体中选择；先调字号、字距和行距，再调整内边距和位置 | 在目标软件导出同尺寸图，检查实际字形、标点、贴边和重叠；原字体不明或仍有差异时如实记录 |

《核心破局》是本节的来源案例。该次按用户指示将三处红色刷痕与三处思政色区改成可直接编辑的色框，随后在另存版中移除整页窗景并设置可换色白底。新任务应从当前要求决定是否简化色框或去背景；案例中的对象数量、颜色和外形不作为默认参数。

## 二、在可编辑底稿上加动画

### 选用模板与保护对象

本例查阅的开源项目是视频动效资源库，本地动态模板才提供可编辑的演示软件时间轴。选型前先确认模板输出的是原生效果还是视频、网页预览等成品；后者可作视觉参考，不能代替原生动画。模板索引查到零条时，先检查索引里的根目录、记录数量和实际文件，再只读检索原模板；不要据空索引认定模板不存在，也不要覆盖原模板或共享索引。

用户要求给已有可编辑稿加动画时，先复制当前指定底稿，以它的页面构图和最终停留画面为准。复用动态母版里已经过验证的时间轴、效果和转场结构，绑定当前页面的对象。模板本身是用户指定底稿时，沿用该模板的布局与绑定关系，再做获准的内容替换。仅做截图复刻时，没有新增动效或改版的授权。

确需让图片、牌匾和说明一起运动时，只对该动画单元做原生组合，保留成员对象和原标识，让文字、形状、顶点仍能在组内选中编辑；不要把全页打成一组或一张图片。组合可能改变前后层级和裁切，操作后须做静态对照。用户要求对象不组合或须保持在顶层时，改用分对象同步动画。替换有动画的图片优先用软件的替换图片操作，避免删除后重插导致绑定丢失。

### 常见故障与验证办法

| 发现的问题 | 实际处理办法 | 复检与结果边界 |
|---|---|---|
| 直接通过原生接口给缩放效果设置幅度，接口拒绝该参数 | 用目标软件创建小型样本并保存，检查该效果实际写入的时间轴；可改用模板中已存在的原生缩放行为，明确起始与结束比例，结束时回到原设计尺寸 | 打开最终文件查看动画窗格，核对效果编号、延时、时长与对象；用实际播放或原生视频检查缩放结束位置。某个参数在一种效果上被拒绝，不能推断所有效果都不支持 |
| 只在页面直属节点查找转场，三维切换读取为空 | 对照目标软件生成的样本，兼查直属转场和兼容性包装内的转场。复用时保留包装和回退分支，按需同步设置翻页方式；不要只摘出高级转场子节点 | 保存重开后核对转场实际类型和持续时间；对三维画廊、立方体等至少检查转场过程与停留画面。不以格式通过推定其他播放器兼容 |
| 拷贝时间轴或重组后，动画绑错对象、组内对象丢失，或动画不能自动启动 | 以本页对象映射重绑所有目标；新增组使用未占用标识，原对象标识不随意重排。复用母版时保留与起播、前后翻页相关的时间轴关系；重排时间节点标识时同步更新引用 | 核对最终页数、文字与原对象标识、动画目标存在性、节点唯一性和引用有效性；目标软件重开后检查组内编辑、起播、翻页和触发器。讲解与自动播放按实际需求分别设置，互不覆盖 |
| 视频抽帧脚本打不开含中文的静态预览路径；改读后全部页面仍被判为无末态 | 先区分文件缺失与图像库路径读取失败，使用能读取中文路径的接口或直接从文件字节解码。参考图和视频帧采用一致的取样策略，检查解码色彩、尺寸比例及帧时刻；先抽看几张已知完整帧，再校准匹配方法 | 压缩视频采样只用于定位稳定画面和发现异常，差值不能作为静态保真合格线。需要人工复核关键过渡、播放顺序与停留画面。实际播放检查、原生视频抽检、跨软件兼容应分别记录，未做的检查标为待确认 |

动态版至少保留两组独立证据：一组证明对象与布局保持可编辑，另一组证明播放按预期发生并停在可读状态。静态复刻对照原图；在既有复刻稿上增加动画的改动检查，另对照加动画前的指定底稿。前者的已知差异不会因为后者通过而消失。实测证据要能对应到最终文件版本，不能把预览视频当作可编辑交付稿，也不能仅凭动画项数评价完成度。

## 三、本次记录对应的证据

- 静态项目检查目录中的 `检查汇总.json`、`实际编辑验证.json`、`同尺寸对照索引.json` 和 `图像工具局部修复记录.json`，分别记录已知差异、实改保存重开、原尺寸对照和遮挡修复。本例十页代表性编辑试验和移开全部前景试验通过，严格逐像素一比一未达标。
- 动态项目检查目录中的 `参考来源.json`、`原生动画检查.json`、`原生对象保留核验.json` 和 `实际动态画面检查.json`，分别记录模板机制、原生动画和文件版本、原有对象保留及实际视频采样。本例十页有九十九项原生动画；该数量仅为案例记录，不是其他任务的目标。
- 《核心破局》项目中的「编辑与移开试验」「透明素材检查」及「背景可更改版」的检查记录，分别记录色框和顶点的实改、明暗底复检、背景换色后保存重开与前景对象核对。
- 以上文件位于各自项目目录，技能包不依赖其存在；仅在复查历史项目时使用。新任务应在自己的检查目录留下同类证据。
