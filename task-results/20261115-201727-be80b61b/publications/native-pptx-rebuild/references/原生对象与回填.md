# 原生对象、顶点和指定页回填

## 坐标和文字

保存源图像素尺寸及目标画布尺寸，所有坐标、图片和字号使用同一换算。常规文字的磅值按 `像素字号 × 目标画布高度（英寸）× 72 ÷ 源图高度（像素）` 换算，再用实际字形和换行校准；固定像素字号不能直接当磅值。

原图决定内容与位置，参考文件仅决定对象类型与拆分粒度。移动或改填色时不改写字体、字距和富文本格式；只修改用户指定的属性。

按每页对象登记表保存原图坐标尺寸、颜色及透明度、对应文件中的对象标识和实际测试证据。源元素到原生对象的映射逐一核对，不用对象总数推断覆盖完整。无法识别的原字体先核查，不能擅自换字体后宣称一比一。

### 字体识别与还原

1. 有与原图对应的原始演示文稿时，优先读取文字段的字体名称、字号、字重、字距、段落行距等属性；字体未直接声明时解析主题字体和东亚字体等继承信息，不能把空字体名称当成已识别。
2. 只有图片时，先观察字形、衬线、字面比例、笔画粗细、数字及标点形态，比较候选字体的实际渲染；记录识别依据和不确定项，不凭印象把近似字体说成原字体。
3. 核查电脑字体列表、字体文件或实际渲染结果，确认原字体是否已安装、实际能否使用。文稿中出现字体名称不代表系统已有该字体，防止静默替换。
4. 找不到原字体时，从当前可用字体中选外观最接近的替代字体，记录原字体或待确认候选、未找到的检查结果、替代字体及选择依据。替代不代表一比一要求自动降低，保留不能消除的差异记录。
5. 字体确定或更换后，重新检查字号、实际字宽、行距、字距、文字位置、基线、换行及溢出；不得只替换字体名称就交付。以同尺寸渲染、叠加与局部差异图复核，再调整框和位置。

将字体来源、安装情况、使用的原字体或替代字体、复检证据记入对象登记和检查记录；不把尚未安装或未经实际检查的字体写成已还原。

## 具有文本能力的自由轮廓

斜边、非对称切角、圆角横幅以原生自由曲线实现。分别量左右斜距和每个角的半径或切线距；前景色块、描边与外层底框同步校准。普通预设形状足够贴合时无需强制自由曲线。

需要同时改字的色区在同一原生对象上保留文本体。用自定义几何记录直线、曲线及控制柄，保证填色、文字和顶点能力保留；不能仅把轮廓转成图片或透明矢量图片。

构建演示文件内部标记时保持对象属性顺序：变换和几何之后写填充，在线条之前；背景填充按当前库可用接口写入。历史某版本验证过的私有接口仍需在当前环境复核。

原生软件中分别查询 `Nodes.Count` 与 `HasTextFrame`；顶点数量不单独证明轮廓贴合，需要同时看参考与最终预览。只有实际做过界面拖动，才能描述为“手工逐点调整”。

验证副本中在同一不规则文本框实际改字、改填色并移动顶点，保存再打开检查。通过原生节点接口改动时如实记录，不能写成界面操作。交付稿保留原始节点与控制柄；测试后恢复也需重新做轮廓和视觉对照。

## 严格视觉对照闭环

从最终文件直接原生渲染到原图尺寸。原图和渲染图不得自动配准、平移、重采样后当成通过证据，这些操作可能掩盖实际错位。按原坐标生成半透明叠加、绝对差异图及每个登记对象的局部误差，分别检查文字、线条、斜边、圆角、透明素材与背景。

每一处差异登记后修正；修改后更新受影响区域，交付前重新生成整页对照。字体与抗锯齿差异需有验证依据才能说明原因。总平均值、对象数量、包结构通过都不能替代局部及可编辑性验收，不设置自动降级的一致性阈值。

以最终文件摘要绑定全部证据；文件后续有任何修改，旧渲染不能继续作为新版本的最终证据。保留原尺寸数据用于计算，只把压缩副本或原尺寸局部的压缩放大图提供给模型查看。

## 复杂对象的编辑边界

照片、人物和质感插画整体可移可替换；不承诺逐笔编辑。简单柱、线和图例可原生重建，但没有原始数据表时，不把它声明为数据驱动图表。未要求恢复表格数据和动画时，不擅自扩展为这些任务。

普通文字可独立修改，色块可独立改色，不规则文本框可改文字、颜色与顶点。复杂插画默认只有整体移动、缩放和替换能力；头发、衣服、五官等内部细节若也要单独编辑，需要另外矢量化或重建为原生图形，并验证各部件。透明图片、带透明通道的矢量图片或可整体替换的素材，均不能直接证明内部细节已原生可编辑。

## 回填最新底稿

1. 重新读取最新指定文件的页数和目标页标题；锁定是替换还是追加。原位替换使用目标位置，不在末尾追加重复页。
2. 先确定导航下可用画布，再统一缩放几何、图片及字号；不能只缩形状不缩字体。
   原图不含导航时，登记主体的固定导航偏移和等比映射，从原生渲染中按登记区域裁出主体作同尺寸对照；整页导航另行核验。不得自动配准或拉伸原图来迁就画布，也不能将主体区域通过表述为整个页面逐像素一致。
3. 从最新底稿保留一套导航，当前栏目正确高亮；页脚、底线和其他页不随重建内容一起移动。
4. 跨文件拷贝重映射媒体关系、对象标识及内部链接，更新内容类型和目标路径。内部媒体名优先简单代码标识，对外交付文件名可中文。
5. 保留未修改页面的原始内容与关系。若承诺逐字节保持，比较相应页面、关系和依赖部件；否则如实报告已经完成的文本、对象或渲染级对照。
6. 结构检查后实际打开最终文件并渲染目标页；跨页导航、页序、页脚及非目标页再单独检查。

原生导出只关闭本次打开的验证副本，不退出用户的演示软件。预览先压缩，再交给模型看图。
