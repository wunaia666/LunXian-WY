# 一比一还原与原生可编辑增强说明

当前版本：1.4。以下保留各版历史记录。

版本：1.1。此版本在原有六节结构、三个技术参考文件和检查工具上增量修改。

- 增加最高制作原则：当前原图是唯一视觉参照，一比一外观与原生可编辑必须同时满足；删除原先允许轻微视觉差异的放宽表述。
- 明确逐项保留文字、字体、字号、颜色、位置尺寸、间距、线条、形状、圆角、透明度及层级；不擅自美化、简化或改写内容。
- 强制不规则文本框在同一原生对象中具备改字、改填色与编辑顶点能力；保留前景与底框同步修正、完整透明主体及导航回填经验。
- 增加每页对象登记模板，记录源图坐标颜色、对象类型、最终对象标识、独立编辑能力、验收方法和差异修正证据。
- 增加原尺寸导出、半透明叠加、绝对差异及局部放大工具。拒绝尺寸不一致或过期导出记录，绑定原图、渲染与最终文件摘要；数值阈值只用于定位，不自动判合格。
- 扩充实际编辑试验：文字内容与颜色、填充、背景、图片移动缩放替换、不规则文本框实际改顶点、移开对象检查残留，保存重开；交付稿恢复原图外观后重新对照。
- 所有视觉检查必须循环修正，修改后复检受影响区域，最终再次整页核验；未解决差异不得被平均值、对象总数或结构检查通过掩盖。
- 保留原有主技能与技术经验库的分工。完整包包含三个参考文件、原检查工具、新视觉工具、登记模板、依赖清单和测试。

本次交付为技能更新与工具验证，不表示已经对新的用户截图完成一比一复刻。历史案例和未知根因仍按原有证据规则处理。

## 1.2版：只补充用户指定的四项

本节为1.2版追加记录，上文1.1版历史说明保留。六节主结构、一比一最高原则及其他既有技术与验收规则继续保留。

1. 图片按“原始文稿提取、截图抠取或遮罩、必要修复、最后重生”的顺序取得；重生仍须外观对照，取得方式如实登记。
2. 字体优先读原始文稿；截图识别字形并核查本机安装；缺字库时选择最接近的可用字体，复检字号、字宽、行距及位置。
3. 核对七项必需文件和两个脚本参数，按正文示例实际运行；完整包保留全部依赖、参考、模板和工具。
4. 明确复杂插画默认整体移动、缩放和替换；内部头发、衣服、五官等独立编辑需要额外矢量化或原生重建，未执行不得承诺。

配套对象登记模板仅新增图片来源和字体还原记录。本轮不改变检查脚本、依赖版本、历史案例文件或其他既有规则。

## 1.3版：补充复刻与动效故障排查

- 新增[复刻与动效故障排查](references/复刻与动效故障排查.md)，记录《南宋人生》复刻和动画增强中遇到的问题、实际处理办法及复检证据。
- 主技能加入按需加载入口，并明确动态模板只负责动效机制，原生编辑、静态保真和回填要求继续按本技能执行。同步把旧案例的透明主体处理说明改为与既有素材优先级一致。
- 检查脚本、对象登记模板、依赖和一比一验收标准保持原有要求。历史案例的近似字体、局部修复、采样数值和时长均不作为新任务默认值。

## 1.4版：补充背景换色、色框和透明插画检查

- 区分保留原图但让背景可换色，以及移除场景背景后保留可更换底色。通过实际换色、保存重开和检查可见空隙，确认新底色未被遮挡。
- 明确带填色文本框的内容、底色与边框属于同一原生对象，保留不规则外沿时实测改顶点；只在用户授权时简化原轮廓。
- 补充浅色插画的保护遮罩、明暗底边缘检查、旧字标清理及局部组合；分层移开对象，检查原位和底层。
- 保留原图保真标准及检查工具。实例和处理办法见[故障排查](references/复刻与动效故障排查.md#背景换色色框与透明插画)。
