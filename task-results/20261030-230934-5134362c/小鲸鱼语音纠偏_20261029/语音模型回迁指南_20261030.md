# 语音模型回迁指南（外机训练 → 本机使用）

核对时间：2026-10-30。本机实测：RTX 3060 Laptop 6 GB，三代模型 fp16 常驻 2823 MB，余 3320 MB。

## 结论先说

- **推理能跑，训练跑不了。** 本机 6 GB 显存只够加载 0.5B 底座做推理；CosyVoice 的微调至少需要 16–24 GB，必须在外机或云上做。
- 外机训练时**请限定 0.5B 底座**（CosyVoice2-0.5B / Fun-CosyVoice3-0.5B），训 1.5B/3B 拿回来本机也跑不动。

## 一、外机训练完，到底要带什么回来

按训练方式分三种，带的文件完全不同：

| 训练方式 | 产物 | 回传体积 |
|---|---|---|
| A. 只是零样本克隆并保存说话人（`add_zero_shot_spk`） | 模型目录下的 `spk2info.pt` | 几 MB |
| B. 全量/部分 SFT 微调（官方 run.sh 第 5、6 阶段） | `llm.pt`（1.9 GB）、可选的 `flow.pt`（1.2 GB） | 1.9–3.2 GB |
| C. 换了更大底座或改了结构 | 整套模型目录 + 对应 `cosyvoice*.yaml` + `CosyVoice-BlankEN` | 5 GB 以上 |

官方训练产物位置（CosyVoice3 示例）：

```
examples/libritts/cosyvoice3/exp/cosyvoice3/llm/torch_ddp/   # 各 epoch 检查点
examples/libritts/cosyvoice3/exp/cosyvoice3/flow/torch_ddp/
```

第 6 阶段用 `cosyvoice/bin/average_model.py` 取最近 5 个 epoch 平均，得到单文件 `llm.pt` / `flow.pt`，**这个才是能直接加载的东西**。

### 外机打包

```bash
cd /path/to/CosyVoice
git rev-parse HEAD > 版本.txt
cd examples/libritts/cosyvoice3
tar -czf ~/回迁模型.tar.gz \
  exp/cosyvoice3/llm/torch_ddp/llm.pt \
  exp/cosyvoice3/flow/torch_ddp/flow.pt
sha256sum exp/cosyvoice3/llm/torch_ddp/llm.pt >> ~/版本.txt
```

把 `回迁模型.tar.gz` 和 `版本.txt` 一起带回来（网盘/U 盘/局域网都行，3 GB 左右）。

## 三、6 GB 显存可行性

| 底座 | fp16 显存 | 本机 |
|---|---|---|
| 0.5B（现在用的） | 约 2.8 GB | ✅ 能跑，余 3.3 GB |
| 1.5B | 约 6–7 GB | ❌ 不够，需要 int8 量化或 CPU offload（很慢） |
| 3B | 约 12 GB | ❌ 不可能 |

另外：合成时不要同时开雷电模拟器和大浏览器，显存会不够；服务里已有"余量低于 2.4 GB 就告警"的保护。

## 四、五个真实的坑

1. **代码版本必须一致**。权重是 state_dict，yaml 结构或 tokenizer 一改就可能加载失败或出声不对。要回传 `git rev-parse HEAD`。
2. **官方 run.sh 第 6 阶段路径写错**：average_model 那几行写的是 `exp/cosyvoice/`，cosyvoice3 实际目录是 `exp/cosyvoice3/`，要手改，否则说找不到 checkpoint。
3. **deepspeed 分片不能直接用**。`model+optimizer` 状态要先用 `average_model.py` 或按 state_dict 导出成单文件。
4. **采样率固定 24 kHz**，训练数据不是 24k 会先被重采样，音色会变。
5. **CosyVoice3 训练需要 `--qwen_pretrain_path`**，tokenizer 也在 `CosyVoice-BlankEN` 里，这套要跟推理端一致。

## 五、数据量的现实

微调需要**同一说话人、干净、至少 30 分钟（最好 1–10 小时）**的音频。本机现有的唯一目标素材是那条 8 秒视频——**8 秒训不了**，硬训只会过拟合、出现杂音或串词。

所以：如果你要的还是那条视频的声音，继续用现在的零样本克隆 + 逐句音高校准（实测基频 461 Hz、与参考音余弦 0.67，旧链路是 333 Hz / 0.23），不要去训。外机训出来的如果是别的数据，那也不是这个声音。

## 六、自检脚本

`E:\sss_test\tools\verify_voice_model.py`

```bash
# 只核对文件（不占显存，随时可跑）
python verify_voice_model.py --engine cosyvoice3 --model-dir <模型目录> --no-load

# 完整自检（会加载模型并试合成，需先停服务）
python verify_voice_model.py --engine cosyvoice3 --model-dir <模型目录>
```

输出包含：每个必需文件的体积、yaml 头几行、加载耗时、显存占用与余量、试合成时长、基频、与指定原声的声纹余弦。
