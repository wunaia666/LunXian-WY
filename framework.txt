============================================================
        个人主页网站框架 - 海底世界风格
============================================================

参考项目: https://github.com/R0272/My_introduction
原始主题: 森林/绿色自然系
目标风格: 海底世界（深蓝色/海洋色系 + 珊瑚元素 + 海洋生物风）

============================================================
一、网站结构（4个页面）
============================================================

index.html          ← 封面/入口页（头像 + 个人信息 + "进入"按钮）
html/
  home.html          ← 主页（自我介绍 + 4个兴趣图标入口）
  detail.html        ← 兴趣详情页（音乐/阅读/运动/摄影 四大板块）
  message.html       ← 留言树屋（留言板 + 登记表 + 日历）
css/
  base.css           ← 公共样式（重置 + 左侧导航 + 返回顶部 + 页脚）
  index.css          ← 封面页样式
  home.css           ← 主页样式
  detail.css         ← 详情页样式
  message.css        ← 留言页样式
img/                 ← 所有图片资源（见下方清单）

============================================================
二、页面详细结构
============================================================

【1. index.html - 封面页】
├── 全屏背景图（温馨可爱风格）
├── 居中半透明卡片
│   ├── 头像（圆形，白色边框）
│   ├── 姓名
│   ├── 学校/专业
│   ├── 欢迎语
│   └── "进入" 按钮（圆角胶囊形，hover变色）
└── 引用: css/index.css + css/base.css

【2. home.html - 主页】
├── 全屏背景图（可爱插画风房间/花园场景）
├── 文字介绍区（叠在背景图上方）
│   ├── 标题: 问候语
│   └── 多行自我介绍
├── 4个可点击兴趣图标（绝对定位在背景图上）
│   ├── 🎵 音乐 → detail.html#music
│   ├── 📷 摄影 → detail.html#photo
│   ├── 🎬 国漫 → detail.html#anime
│   └── 🏃 运动 → detail.html#sport
├── 左侧悬浮导航栏（封面/主页/兴趣/留言）
└── 引用: css/home.css + css/base.css

【3. detail.html - 兴趣详情页】
├── 顶部介绍区（半透明白色卡片）
├── 导航按钮条（音乐/国漫/运动/摄影 锚点跳转）
├── 🎵 音乐板块
│   ├── CD唱片卡片区（6张，圆形封面，hover旋转）
│   │   每张: 封面图 + 歌名 + 一句话感悟
│   └── 歌手卡片区（2位歌手）
│       每位: 照片 + 歌手名 + TOP 8歌单列表
├── 🎬 国漫板块
│   ├── 热门国漫推荐卡片区（5张，圆形封面）
│   │   每张: 图标 + 作品名 + 一句话简介
│   └── 国漫详情卡片区（5部作品）
│       每部: 图标 + 作品信息（原著/类型/简介）
├── 🏃 运动板块
│   └── 3个运动卡（并排）
│       每个: 标题 + 描述 + 图片 + 可选视频链接
├── 📷 摄影板块
│   └── 照片墙（多张照片，默认窄条，hover展开）
├── 结束语（感谢 + 邀请留言）
├── 页脚（导航链接 + 联系方式）
├── 左侧悬浮导航栏
└── 引用: css/detail.css + css/base.css

【4. message.html - 留言树屋】
├── 顶部标题区（半透明卡片）
├── 留言板表单
│   ├── 昵称输入
│   ├── 邮箱输入
│   ├── 留言内容（textarea）
│   └── 提交按钮
├── 树屋居民登记表
│   ├── 个人信息 fieldset（姓名/地址/生日/性别）
│   ├── 喜好调查 fieldset（radio + checkbox）
│   ├── 你的建议 fieldset（textarea）

├── 左侧悬浮导航栏
└── 引用: css/message.css + css/base.css

============================================================
三、共用组件（每个页面都有的部分）
============================================================

1. 左侧悬浮导航栏 (.box)
   - 固定在左侧，圆角矩形，温馨色背景
   - 4个链接: 封面页 / 我的主页 / 兴趣爱好 / 留言树屋
   - 当前页高亮显示 (.active)

2. 返回顶部按钮 (.box-right)
   - 固定右下角，圆形图标按钮
   - 仅 detail.html 使用

3. 页脚 (#footer)
   - 导航链接 + 联系信息

四、风格定义 - 海底世界
============================================================

【配色方案】
- 主色: #0a2a43 (深海蓝) / #1a5276 (海洋蓝)
- 辅色: #2e86c1 (浅海蓝) / #85c1e9 (海面蓝)
- 点缀: #ff6b81 (珊瑚粉) / #a29bfe (珊瑚紫) / #ff9f7f (珊瑚橙)
- 背景: #0a2a43 (深海底) / #1a5276 (海底) / #2e86c1 (海中)
- 文字: #ecf0f1 (白色) / #d4e6f1 (浅蓝白) / #bdc3c7 (银灰)
- 卡片背景: rgba(10, 42, 67, 0.6) 半透明深蓝
- 导航栏: rgba(10, 42, 67, 0.8) 深蓝玻璃

【字体】
- 标题: "楷体" 或海洋风格字体
- 正文: "微软雅黑"
- 英文: "Comic Sans MS" 或 "Segoe UI"

【圆角 & 阴影】
- 卡片圆角: 18-24px
- 按钮圆角: 20-30px（胶囊形）
- 阴影: 0 6px 12px rgba(0, 0, 0, 0.3) 深色阴影
- 边框: 1px solid rgba(135, 206, 235, 0.2) 海蓝边框

【动画效果】
- 卡片 hover: scale(1.05) + 阴影增强 + 边框发光
- CD封面 hover: rotate(360deg) 旋转 + 边框变亮
- 照片墙 hover: 展开变宽 + 阴影增强
- 页面进入: fadeIn 淡入动画
- 图标 hover: scale(1.1) + translateY(-5px) 上浮
- 海底气泡: bubble-rise 上升动画
- 海底光线: shimmer 闪烁动画

七、技术要点
============================================================

1. 纯静态 HTML + CSS，无 JavaScript 框架
2. 所有样式用 CSS 实现（动画、hover效果、布局）
3. 左侧导航栏: position: fixed 定位
4. 主页兴趣图标: position: absolute 叠在背景图上
5. 照片墙效果: 默认窄条 width:72px，hover展开 width:528px
6. CD封面旋转: transition: transform 9s ease + hover rotate(360deg)
7. 页面背景: background: url() no-repeat center center fixed + cover
8. 卡片半透明: background-color: rgba(10, 42, 67, 0.6)
9. 响应式: 可选，原项目未做响应式
10. 海洋主题: CSS变量 + 渐变背景 + 毛玻璃效果
