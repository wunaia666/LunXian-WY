# 悦美美业视觉重制说明

## 设计参考

本次实际查阅了以下开源项目：

- [开源后台界面组件库](https://github.com/tabler/tabler)：借鉴统一留白、指标层次与卡片间距；查阅其样式变量文件，按电子表格原生能力重新排版，没有将网页样式误称为电子表格插件。
- [开源后台管理模板](https://github.com/coreui/coreui-free-bootstrap-admin-template)：参考导航、筛选与统计区域的分工。
- [开源线条图标库](https://github.com/tabler/tabler-icons)：实际使用金额、门店、客户、趋势、提醒、日历六枚图标，保留原始图标与许可文件。转换后以透明图片嵌入。

图标与界面项目的原始许可分别保存于美化素材目录。网页模板的组件不能直接运行于工作簿，本次保留原生可编辑图表与单元格筛选。

## 视觉规范

- 暖白画布：#F5F1ED。
- 纯白数据面板：#FFFFFF。
- 标题与正文：#49352F。
- 玫瑰棕重点色：#956758。
- 次要数据：#DDCCBF。
- 回访走势：#BA8565。
- 辅助文字：#786C65。
- 分隔线：#E9E0D9。
- 逾期提醒：#A34D45。

展示标题采用宋体，中文正文采用微软雅黑，指标数字采用无衬线字体。摄影只放在两张展示页的顶部独立区域，以原始比例完整显示；不裁切、不覆盖指标与图表。业务表统一表头颜色，不修改业务公式、内容或条件提醒规则。

## 配图制作

两张图片使用本次会话的内置图片生成工具制作。项目内保留适合内嵌的压缩图片；工作簿内嵌图像，不依赖外部图片路径。

### 护理静物提示词

摄影级横向护理静物，精华瓶、奶白瓷碟与白色兰花，暖米白洞石台面，浅杏微水泥墙，日光斜照。暖白、浅沙色、玫瑰棕色调，物体集中于右侧，左侧留白。真实材质与柔和阴影，画面精简。无文字、品牌、水印、人物或图表，完整呈现画面，用于页首独立图片区。

### 护理空间提示词

摄影级横向美容护理空间，暖白墙面和弧形壁龛，浅米护理床，玫瑰棕织物，白色兰花与柔和窗光。暖白、燕麦、沙色为主，建筑杂志摄影，留白充足，材质自然。无人物、文字、标志、水印或图表，构图完整，用于分析页顶部独立图片区。

## 制作方式

先按原说明生成包含十张动态图表的工作簿，再运行美业视觉脚本：

```powershell
python 美业视觉.py --source "动态图表旗舰版.xlsx" --output "美业视觉重制版.xlsx" --qa-dir "检查结果"
python 核对交付.py --source "原始日历工作台.xlsx" --target "美业视觉重制版.xlsx" --qa-dir "检查结果"
```

该步骤会重排两张展示页、嵌入摄影与图标，保留原生图表及动态引用。最后检查原表内容、公式错误、改名转发、月份天数和门店筛选。
