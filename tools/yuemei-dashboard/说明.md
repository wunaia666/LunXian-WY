# 悦美动态图表看板

为现有客户管理工作簿增加两页原生图表，保留原有客户、服务、回访、生日关怀与日历工作台。

## 新增内容

- 经营驾驶舱：年月与门店筛选、六项关键指标、消费与回访组合走势图、新老客结构、门店消费贡献、计划完成情况。
- 图表分析中心：近六个月消费走势、服务项目构成、员工回访排行、逾期时长分布、开卡结构、周内到店节奏。
- 图表数据：隐藏的统计层，保留可追踪的原生公式。

共十张原生图表，支持继续编辑图表、改变配色和查看数据源；没有将图表转成静态图片。

## 联动范围

在经营驾驶舱修改年份、月份和门店范围，两页图表同步更新。日趋势会根据月份自动显示对应的天数。员工排行会根据当前门店只显示有效人员，最多显示前九位；人员表预留四十个读取位置。

服务金额与到店按服务日统计。消费与回访走势图、员工回访排行按实际完成日统计。计划完成率按计划日所在月份统计，并排除已停用任务。客户分类、开卡、逾期和生日提醒反映当前状态。

原有日历工作台保留自己的年月和门店选择，不修改原有业务口径。

## 视觉规范

主色为深绿，辅以灰绿、浅橄榄色与米白。采用实底数据面板、细分隔线和统一字体；消费与回访使用不同颜色，并分别标注两侧坐标单位。所有图表均无三维透视与发光渐变。

## 运行条件

需要安装微软电子表格软件的视窗系统，以及工作簿读写库和系统自动化库。依赖包列在本目录的依赖清单中。

先运行构建脚本，指定原始工作簿、新输出文件和检查目录；随后运行交付核对脚本。构建过程不会覆盖原始文件。

```powershell
python 构建图表看板.py --source "原始日历工作台.xlsx" --output "动态图表旗舰版.xlsx" --qa-dir "检查结果"
python 核对交付.py --source "原始日历工作台.xlsx" --target "动态图表旗舰版.xlsx" --qa-dir "检查结果"
```

## 验证内容

构建脚本会核对全部门店、单店和空月份；检查日趋势天数、星期分布、消费项目合计和逾期分组。还会临时录入一条服务记录，确认金额、次数与图表更新，再恢复原始行。

交付脚本核对原始单元格、公式错误、外部链接和图表数量，并将文件复制改名后重新打开，验证二月份与门店筛选仍可联动。

此目录仅含制作代码，不包含客户工作簿、客户资料、个人凭据或本地检查图片。

## 美业视觉重制

新增暖白、玫瑰棕配色的美业视觉版本，使用两张护理主题摄影与六枚开源图标。摄影在页首独立显示，按原比例完整嵌入，不遮挡指标与图表。业务表同步统一表头颜色。

在原动态图表工作簿生成后运行：

```powershell
python 美业视觉.py --source "动态图表旗舰版.xlsx" --output "美业视觉重制版.xlsx" --qa-dir "检查结果"
python 核对交付.py --source "原始日历工作台.xlsx" --target "美业视觉重制版.xlsx" --qa-dir "检查结果"
```

完整参考项目、色值、图片制作提示词及素材使用说明见本目录的视觉设计说明。
